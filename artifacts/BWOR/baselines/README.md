# BWOR Baseline Results

`bwor_baseline_summary.csv` records the aggregate counts reported for BWOR over 82 public records. Accuracy is computed as `correct / total * 100`.

The table is a compact public summary rather than a raw provider-log dump. Raw logs are excluded from GitHub because they can contain provider diagnostics, local paths, and execution traces. Re-run the evaluation scripts in a configured local environment to generate fresh per-instance outputs.
